# mcp-weather-server

MCP-сервер с mock-данными о погоде. Работает как дочерний процесс главного приложения через stdio-транспорт MCP.

Предоставляет LLM текущую погоду, многодневный прогноз и индекс качества воздуха для городов. Данные предопределены для 7 крупных городов; для остальных генерируются случайные реалистичные значения.

---

## Структура модуля

```
mcp-weather-server/
├── build.gradle.kts
└── src/main/kotlin/mcpweather/
    ├── Main.kt               # Точка входа: инициализация MCP-сервера
    └── tools/
        └── WeatherTools.kt   # 3 MCP-инструмента + предопределённые профили городов
```

## MCP-инструменты

### `get_current_weather`
Текущие погодные условия в городе.

| Параметр | Тип    | Обязателен | Описание                               |
|----------|--------|------------|----------------------------------------|
| `city`   | string | да         | Название города (RU или EN, любой регистр) |

---

### `get_forecast`
Многодневный прогноз погоды.

| Параметр | Тип    | Обязателен | Описание                          |
|----------|--------|------------|-----------------------------------|
| `city`   | string | да         | Название города                   |
| `days`   | number | нет        | Число дней 1–7 (default 3)        |

---

### `get_air_quality`
Индекс качества воздуха (AQI) и концентрации загрязнителей.

| Параметр | Тип    | Обязателен | Описание        |
|----------|--------|------------|-----------------|
| `city`   | string | да         | Название города |

AQI генерируется случайно в диапазоне 10–150:
- ≤ 50 → `Good`
- ≤ 100 → `Moderate`
- > 100 → `Unhealthy for sensitive groups`

## Примеры

### Пример 1 — текущая погода

**Входные данные:**
```json
{
  "tool": "get_current_weather",
  "arguments": { "city": "Tokyo" }
}
```

**Выходные данные:**
```
=== Current weather in Tokyo ===
Condition : Clear
Temp      : 15°C (59°F)
Humidity  : 60%
Wind      : 8 km/h
```

---

### Пример 2 — прогноз на 3 дня

**Входные данные:**
```json
{
  "tool": "get_forecast",
  "arguments": { "city": "London", "days": 3 }
}
```

**Выходные данные:**
```
=== 3-day forecast for London ===
Day 1: Rain, 8°C, wind 18 km/h
Day 2: Облачно, 6°C, wind 21 km/h
Day 3: Туман, 10°C, wind 15 km/h
```

День 1 — базовые данные профиля города; дни 2+ — случайные условия из пула с вариацией температуры ±3 °C и ветра ±5 км/ч.

---

### Пример 3 — качество воздуха

**Входные данные:**
```json
{
  "tool": "get_air_quality",
  "arguments": { "city": "Москва" }
}
```

**Выходные данные:**
```
=== Air quality in Москва ===
AQI      : 67 (Moderate)
PM2.5    : 34 μg/m³
PM10     : 51 μg/m³
NO₂      : 28 μg/m³
```

---

### Пример 4 — неизвестный город

**Входные данные:**
```json
{
  "tool": "get_current_weather",
  "arguments": { "city": "Томск" }
}
```

**Выходные данные** (случайные реалистичные значения):
```
=== Current weather in Томск ===
Condition : Overcast
Temp      : -1°C (30°F)
Humidity  : 73%
Wind      : 17 km/h
```

## Сборка и запуск

```bash
# Сборка fat JAR
./gradlew :mcp-weather-server:shadowJar

# Сервер запускается главным приложением через ProcessBuilder (stdio)
# Ручной запуск для тестирования:
java -jar mcp-weather-server/build/libs/mcp-weather-server-all.jar
```

## Ключевые детали реализации

- **Mock-данные**: реального API погоды нет; все значения предопределены или генерируются случайно
- **Поиск города**: нечувствителен к регистру, поддерживает русские и английские названия
- **Прогноз**: первый день — детерминирован (из профиля); последующие — случайны
- **AQI**: всегда случайный, даже для известных городов
- **Формат ответа**: plain text, не JSON
